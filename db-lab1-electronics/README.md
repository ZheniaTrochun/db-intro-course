Роботу виконано індивідуально.

Основний документ — [звіт](REPORT.md). У ньому наведено призначення системи, вимоги, бізнес-правила, ER-діаграму, сутності, зв’язки та сценарії перевірки моделі.

- [Перевірка комплекту](CHECKLIST.md) — відповідність результатів пунктам завдання.

## Відтворення зображень

Потрібні Node.js та npm. У цій теці виконайте:

```sh
npm install
npm run render
```

Скрипт читає `model/electronics-er.dot` і створює PNG та SVG. SQL-схема не входить до цієї роботи: її реалізація передбачена в лабораторній роботі №2.
