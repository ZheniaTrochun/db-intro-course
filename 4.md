## 2. Специфікація та пояснення аналітичних запитів

| № | Категорія запиту | Що робить запит та навіщо він потрібен | Очікуваний / фактичний результат |
| :--- | :--- | :--- | :--- |
| **1.1** | Базова агрегація (`COUNT`) | Підраховує загальну кількість товарів у таблиці `product`. | Повертає 1 рядок із кількістю товарів (`3`). |
| **1.2** | Базова агрегація (`AVG`, `MIN`, `MAX`) | Обчислює середню, мінімальну та максимальну ціну товару в каталозі. | Повертає агреговані цінові показники по всіх товарах (`1282.67`, `499.00`, `1899.00`). |
| **1.3** | Базова агрегація (`SUM`) | Підсумовує загальну кількість одиниць товарів на складі (`product_item`). | Повертає сумарний залишок по всіх варіаціях (`90` од.). |
| **2.1** | Групування (`GROUP BY`) | Групує замовлення за їхнім статусом (`order_status`) та рахує кількість замовлень у кожному статусі. | Повертає кількість замовлень для кожного наявного статусу (`Processing`, `Delivered`, `Pending`). |
| **2.2** | Групування (`GROUP BY`) | Групує позиції складу за кольором (`product_item_color`) і підраховує сумарний залишок для кожного кольору. | Показує залишки по кольорах (`Білий` — 55, `Синій` — 23, `Чорний` — 12). |
| **2.3** | Фільтрація груп (`HAVING`) | Відфільтровує групи кольорів після групування, залишаючи лише ті, де сумарний залишок > 20 од. | Виводить лише кольори `Білий` (55) та `Синій` (23); `Чорний` (12) відсіюється. |
| **3.1** | `INNER JOIN` | Об'єднує `"order"` і `customer` за `customer_id`, щоб вивести замовлення разом з ім'ям та прізвищем клієнта. | Повертає лише замовлення, які мають відповідного клієнта в базі. |
| **3.2** | `LEFT JOIN` | Виводить усі категорії з `category` та пов'язані з ними товари з `product` (включно з категоріями без товарів). | Зберігає всі категорії лівої таблиці; для порожніх категорій підставляє `NULL`. |
| **3.3** | `FULL OUTER JOIN` | Зіставляє всі замовлення (`"order"`) та всі оплати (`payment`) за `order_id`. | Показує як оплачені замовлення, так і неоплачені (де поля `payment` дорівнюють `NULL`). |
| **3.4** | `CROSS JOIN` | Формує декартів добуток таблиць `category` та `product_item` (усі можливі комбінації категорій та розмірів). | Повертає всі пари «категорія — розмір» ($3 \times 5 = 15$ рядків). |
| **4.1** | Багатотаблична агрегація | Об'єднує `customer` та `"order"` через `LEFT JOIN`, групує по клієнтах та рахує суму замовлень кожного клієнта. | Повертає кожного клієнта (навіть без замовлень) і суму його замовлень. |
| **4.2** | Багатотаблична агрегація | З'єднує 3 таблиці (`product`, `product_item`, `order_item`) та підраховує кількість проданих одиниць кожного товару. | Виводить усі товари каталогу та кількість проданих одиниць по кожному з них. |
| **5.1** | Підзапит у `WHERE` | Порівнює ціну кожного товару із середньою ціною по всій таблиці `product`, обчисленою у підзапиті. | Виводить лише ті товари, ціна яких вища за середню (`1282.67`). |
| **5.2** | Підзапит у `SELECT` | Додає до кожного рядка товару стовпець із середньою ціною по всьому каталогу для візуального порівняння. | Повертає назву товару, його ціну та середню ціну по каталогу поруч. |
| **5.3** | Підзапит у `HAVING` | Групує замовлення за клієнтами та через `HAVING` відбирає тих, чий середній чек вищий за загальний середній чек по магазину. | Виводить клієнтів із середнім замовленням вищим за `1449.00`. |

## 3. Повний SQL-скрипт аналітичних запитів (`lab4_olap.sql`)

```sql


-- 1. БАЗОВА АГРЕГАЦІЯ (COUNT, SUM, AVG, MIN, MAX)


-- 1.1. Скільки всього товарів у каталозі
SELECT COUNT(*) AS total_products
FROM product;

-- 1.2. Середня, мінімальна та максимальна ціна товару
SELECT 
    AVG(product_price) AS avg_price,
    MIN(product_price) AS min_price,
    MAX(product_price) AS max_price
FROM product;

-- 1.3. Скільки всього одиниць товару на складі
SELECT SUM(product_item_stock_quantity) AS total_stock
FROM product_item;



-- 2. ГРУПУВАННЯ ДАНИХ (GROUP BY) ТА ФІЛЬТРАЦІЯ ГРУП (HAVING)


-- 2.1. Кількість замовлень за кожним статусом
SELECT order_status, COUNT(*) AS orders_count
FROM "order"
GROUP BY order_status;

-- 2.2. Залишок на складі за кольором
SELECT product_item_color, SUM(product_item_stock_quantity) AS stock_sum
FROM product_item
GROUP BY product_item_color;

-- 2.3. Кольори, де залишок на складі більший за 20
SELECT product_item_color, SUM(product_item_stock_quantity) AS stock_sum
FROM product_item
GROUP BY product_item_color
HAVING SUM(product_item_stock_quantity) > 20;



-- 3. ОПЕРАЦІЇ JOIN (INNER, LEFT, FULL OUTER, CROSS)


-- 3.1. INNER JOIN: замовлення та імена клієнтів
SELECT o.order_id, c.first_name, c.last_name, o.order_price
FROM "order" o
INNER JOIN customer c ON o.customer_id = c.customer_id;

-- 3.2. LEFT JOIN: усі категорії та їхні товари (навіть якщо товарів немає)
SELECT cat.category_name, p.product_name
FROM category cat
LEFT JOIN product p ON cat.category_id = p.category_id;

-- 3.3. FULL OUTER JOIN: усі замовлення та усі оплати
SELECT o.order_id, o.order_price, pay.payment_amount, pay.payment_method
FROM "order" o
FULL OUTER JOIN payment pay ON o.order_id = pay.order_id;

-- 3.4. CROSS JOIN: усі комбінації категорій та розмірів
SELECT cat.category_name, pi.product_item_size
FROM category cat
CROSS JOIN product_item pi;



-- 4. БАГАТОТАБЛИЧНА АГРЕГАЦІЯ (JOIN + GROUP BY)


-- 4.1. Сума замовлень кожного клієнта
SELECT c.first_name, c.last_name, SUM(o.order_price) AS total_orders_sum
FROM customer c
LEFT JOIN "order" o ON c.customer_id = o.customer_id
GROUP BY c.customer_id, c.first_name, c.last_name;

-- 4.2. Кількість проданих одиниць по кожному товару
SELECT p.product_name, SUM(oi.order_item_quantity) AS sold_qty
FROM product p
LEFT JOIN product_item pi ON p.product_id = pi.product_id
LEFT JOIN order_item oi ON pi.product_item_id = oi.product_item_id
GROUP BY p.product_id, p.product_name;



-- 5. ПІДЗАПИТИ (У WHERE, SELECT ТА HAVING)


-- 5.1. Підзапит у WHERE: товари дорожчі за середню ціну
SELECT product_name, product_price
FROM product
WHERE product_price > (SELECT AVG(product_price) FROM product);

-- 5.2. Підзапит у SELECT: ціна товару і середня ціна по каталогу
SELECT 
    product_name,
    product_price,
    (SELECT AVG(product_price) FROM product) AS avg_price
FROM product;

-- 5.3. Підзапит у HAVING: клієнти, чий середній чек вищий за загальний середній чек
SELECT c.first_name, c.last_name, AVG(o.order_price) AS avg_customer_order
FROM customer c
JOIN "order" o ON c.customer_id = o.customer_id
GROUP BY c.customer_id, c.first_name, c.last_name
HAVING AVG(o.order_price) > (SELECT AVG(order_price) FROM "order");
```
