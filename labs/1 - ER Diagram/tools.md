# Модуль Tools

Описує сутності, пов'язані з предметами гри: їхні статичні шаблони (типи предметів), конкретні екземпляри предметів у світі, підтипи предметів (зброя, їжа, броня) та зачарування, що можуть бути на них накладені.

## ItemTemplate

Статична таблиця-каталог усіх типів предметів, що існують у грі — "ItemType", на яку посилаються асоціативні сутності MonsterDrop та NPCItemRelation з модуля World. Головним ключем цієї є id - int generated always as identity. Має атрибути name - varchar(96) NOT NULL для назви предмета, що висвітлюється в UI клієнту гри, та description - varchar(128) NOT NULL для опису предмета. Також визначає max_stack NOT NULL default 1 - максимальний розмір стеку предметів цього типу в одному слоті інвентарю, rarity - рівень рідкісності предмета, icon - посилання на іконку предмета для інтерфейсу, та price - базову вартість предмета.

Один ItemTemplate може відповідати нулю чи багатьом конкретним екземплярам Item, тоді як кожен Item обов'язково посилається рівно на один ItemTemplate.

## Item

Центральна сутність модуля, що представляє конкретний екземпляр предмета, який фактично існує в грі (наразі - у складі інвентарю персонажа). Поєднує посилання на статичний шаблон із власним, індивідуальним станом. Головним ключем є id - int generated always as identity.

item_tmpl_id є foreign key до сутності ItemTemplate, int NOT NULL. Багато до одного: кожен Item посилається рівно на один ItemTemplate, тоді як ItemTemplate може мати нуль або багато відповідних йому екземплярів Item.

inv_id є foreign key до сутності Inventory (модуль Player), int NOT NULL. Багато до одного: кожен Item обов'язково належить рівно одному Inventory, тоді як Inventory може містити нуль або багато Item.

Окрім того, має атрибути inventory_slot - номер слоту в інвентарі, де розташований предмет, та quantity - кількість одиниць предмета в цьому стеку (обмежується значенням max_stack відповідного ItemTemplate).

## Weapon, Food, Armor

Ці три сутності "наслідують" Item, реалізуючи його підтипи (категорії) — кожна зберігає атрибути, специфічні лише для своєї категорії предметів: бойові характеристики зброї, лікувальний ефект їжі чи показник захисту броні. Усі три мають однаковий спосіб зв'язку з Item через foreign key item_id: з боку Item кардинальність нуль або один (Item може не мати відповідного рядка в жодній із цих трьох таблиць, або мати рівно один - залежно від того, до якої категорії він належить), а з боку самої підтипової сутності - рівно один (кожен рядок Weapon, Food чи Armor обов'язково посилається на єдиний конкретний Item).

### Weapon

Головний ключ - id int generated always as identity. item_id - foreign key на Item (один до нуля-або-одного, як описано вище). Також має атрибути attack_speed - швидкість атаки та damage - величина завданої шкоди.

### Food

Головний ключ - id int generated always as identity. item_id - foreign key на Item (аналогічно до Weapon). Має атрибут up_health - кількість здоров'я, що відновлюється персонажу при вживанні предмета.

### Armor

Головний ключ - id int generated always as identity. item_id - foreign key на Item (аналогічно до Weapon). Має атрибут protect - показник захисту, що надає предмет його власнику.

## Enchantment

Зберігає інформацію про зачарування, накладене на конкретний екземпляр предмета. Головним ключем є id int generated always as identity. item_id є foreign key до сутності Item: кожне зачарування прив'язане рівно до одного предмета, тоді як сам предмет може мати нуль або одне зачарування. Також має атрибути ench_level - рівень (сила) зачарування, та effect - опис ефекту, що надає зачарування предмету.
