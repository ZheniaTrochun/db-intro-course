## Ключові особливості дизайну

✅ **UUID Primary Keys** - для масштабованості та розподілених систем
✅ **Unique Constraints** - на email, SKU, order numbers, location codes
✅ **Foreign Key Relationships** - правильна referential integrity
✅ **ENUM Types** - для статусів та одиниць вимірювання
✅ **Normalization** - третя нормальна форма (3NF)
✅ **Scalability** - для майбутнього розширення

## Опис компонентів системи

### SUPPLIER (Постачальники)
- Зберігання інформації про постачальників
- Контактна інформація, адреса
- Unique email для кожного постачальника

### SUPPLY_ORDER (Замовлення)
- Управління замовленнями від постачальників
- Отримання, обробка, скасування
- Загальна вартість і дата поставки

### SUPPLY_ITEM (Позиції замовлення)
- Окремі товари в замовленні
- Кількість і ціна
- Розташування зберігання

### PRODUCT (Каталог товарів)
- Всі товари в системі
- SKU код, опис
- Мінімальний рівень запасів

### WAREHOUSE_LOCATION (Розташування складу)
- Фізичні місця на складі
- Зони, полиці, потужність
- Унікальні коди розташування

### INVENTORY_MOVEMENT (Рух товарів)
- Всі переміщення товарів
- Від якого до якого розташування
- Дата операції

## Технічні рішення

- **PostgreSQL** - рекомендована СУБД
- **UUID** - для primary keys
- **Enum** - для статусів та типів
- **Timestamp** - для аудиту дат
- **Foreign Keys** - для целісності даних
