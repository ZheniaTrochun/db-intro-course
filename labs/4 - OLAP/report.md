Лабораторна робота №4 виконана на структурі бд після виконання запитів попередніх лабораторних

поясення блоків запитів :

- 1 знаходження загальної суми оренди, отриманої з кожного об'єкта нерухомості за весь час
  - `SELECT p.property_id, p.adress, SUM(l.rental_amount) as total_rental_amount` : виводимо ідентифікатор та адресу об'єкта, а також використовуємо агрегатну функцію SUM для підрахунку загальної суми оренди за договорами.
  - `FROM lease_agreement l` : визначаємо головну таблицю угод оренди як основу для вибірки.
  - `INNER JOIN property p ON p.property_id = l.property_id` : внутрішнє об'єднання таблиці нерухомості за ключем property_id, залишаючи лише ті записи, які мають відповідні договори.
  - `GROUP BY p.adress, p.property_id` : групування результатів за конкретним об'єктом та його адресою для коректної роботи агрегатної функції SUM.

- 2 знаходження кількості власників для кожної адреси нерухомості з урахуванням усіх власників
  - `SELECT p.adress, COUNT(o.-) AS total_owners` : виводимо адресу нерухомості та підраховуємо загальну кількість власників за допомогою функції агрегації COUNT.
  - `FROM Property p` : визначаємо таблицю нерухомості як базову.
  - `RIGHT JOIN property_owner o ON o.owner_id = p.owner_id` : праве об'єднання з таблицею власників, що дозволяє включити у вибірку всіх власників, навіть якщо для них не вказана нерухомість.
  - `GROUP BY p.property_id, p.adress` : групування даних за полями нерухомості для виконання агрегації по кожному об'єкту та адресі.

- 3 знаходження кількості угод між кожним орендарем та кожним ріелтором (включно з нульовими значеннями)
  - `SELECT r.full_name AS realtor_name, t.full_name AS tenant_name, COUNT(l.lease_id) AS total_leases` : виводимо ім'я ріелтора, ім'я орендаря та підраховуємо загальну кількість угод між ними за допомогою функції COUNT.
  - `FROM tenant t CROSS JOIN realtor r` : створення декартового добутку (повної матриці) між усіма орендарями та всіма ріелторами для отримання всіх можливих пар.
  - `LEFT JOIN lease_agreement l ON l.tenant_id = t.tenant_id AND l.realtor_id = r.realtor_id` : лівостороннє об'єднання з таблицею угод за складеною умовою для кожної конкретної пари людей, зберігаючи пари навіть за відсутності угод.
  - `GROUP BY t.tenant_id, t.full_name, r.realtor_id, r.full_name` : групування результатів за унікальними ідентифікаторами та іменами орендарів і ріелторів для підрахунку кількості угод для кожної комбінації.
