# Лабораторна робота 3: Маніпулювання даними SQL (OLTP)

**Мета:** протестувати реляційну схему месенджера з лабораторна 2 у PostgreSQL, реалізувавши типові OLTP-операції (`SELECT`, `INSERT`, `UPDATE`, `DELETE`) та транзакції (`BEGIN` / `COMMIT` / `ROLLBACK`) із контролем цілісності даних.

---

## Файли лабораторної роботи

- [`oltp_queries.sql`](./oltp_queries.sql) — повний SQL-скрипт з OLTP-запитами (`SELECT`, `INSERT`, `UPDATE`, `DELETE`), транзакціями та контрольними перевірками.
