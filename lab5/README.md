# Лабораторна робота №5. Нормалізація бази даних

- [Звіт про нормалізацію](normalization.md) містить функціональні залежності, аналіз нормальних форм і команди `ALTER TABLE` для переходу зі схеми лабораторної №2.
- [SQL-скрипт](lab5.sql) створює схему в 3НФ, завантажує зразки та виконує демонстраційні запити.
- [ER-діаграма](er-diagram.svg) показує таблиці, ключі та кратності зв'язків після нормалізації.

Запустіть скрипт у **порожній навчальній базі** PostgreSQL 18. Він видаляє однойменні таблиці й типи перед створенням схеми.

```sh
psql -X -v ON_ERROR_STOP=1 -d lab5 -f lab5/lab5.sql
```

У pgAdmin той самий файл можна виконати в Query Tool.
