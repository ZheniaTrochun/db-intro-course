# Lab 1 — Концептуальна модель БД (ER-діаграма)

## Завдання

Є відеохостинг-платформа **VideoHub** (аналог YouTube). Потрібно спроектувати базу даних,
яка зберігатиме інформацію про користувачів, відео, коментарі, лайки та підписки.

## Вимоги

- Кожен користувач має унікальний email та username.
- Користувач може авторизуватись через Google (googleId) або за паролем.
- Кожен користувач має аватар, банер та опис каналу (необов'язково).
- Кожне відео має назву, опис (необов'язково), URL файлу, мініатюру (thumbnail).
- Відео має лічильник переглядів (за замовчуванням 0).
- Відео належить одному користувачу (автору).
- Користувач може залишати коментарі до відео.
- Коментар містить текст та дату створення.
- Користувач може поставити лайк на відео (один лайк на відео від одного користувача).
- Користувач може підписатись на іншого користувача (канал).
- Підписка унікальна: один користувач може підписатись на іншого лише один раз.
- Кожен запис має дату створення (createdAt).

## Що треба зробити

1. Побудувати ER-діаграму з усіма сутностями та зв'язками.
2. Описати кожну сутність з атрибутами.
3. Пояснити кожен зв'язок прозою.
4. Вказати припущення та обмеження.

## Сутності

| Сутність | Ключові атрибути |
|----------|-----------------|
| User | id (PK), email, username, password, google_id, avatar, banner, description, created_at |
| Video | id (PK), title, description, url, thumbnail, views, created_at, author_id (FK) |
| Comment | id (PK), text, created_at, user_id (FK), video_id (FK) |
| Like | id (PK), user_id (FK), video_id (FK), UNIQUE(user_id, video_id) |
| Subscription | id (PK), subscriber_id (FK), channel_id (FK), created_at, UNIQUE(subscriber_id, channel_id) |

## Зв'язки

| Зв'язок | Кардинальність | Опис |
|---------|---------------|------|
| User → Video | 1:N | Автор завантажує відео |
| User → Comment ← Video | 1:N + 1:N | Коментарі до відео від користувача |
| User → Like ← Video | 1:N + 1:N | Лайки на відео (UNIQUE) |
| User → Subscription ← User | M:N | Підписки на канали (самореференс, UNIQUE) |
