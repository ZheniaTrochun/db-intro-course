# Lab 4 — OLAP: Агрегація, GROUP BY, HAVING, JOIN

## Завдання

Використовуючи БД VideoHub з Lab 2, виконати аналітичні запити (OLAP).

### Базова агрегація

1. **COUNT** — кількість відео на платформі
2. **COUNT(DISTINCT)** — кількість унікальних авторів відео
3. **SUM** — сумарна кількість переглядів усіх відео
4. **MIN / MAX** — мінімальна та максимальна кількість переглядів
5. **AVG** — середня кількість переглядів

### Групування (GROUP BY)

1. Кількість відео кожного автора (User → Video)
2. Сумарні перегляди за автором
3. Кількість коментарів для кожного відео

### Фільтрування груп (HAVING)

1. Автори з більш ніж 1 відео
2. Відео з більш ніж 2 коментарями
3. Автори з сумарними переглядами > 20000

### JOIN

1. **INNER JOIN** — відео з іменами авторів (Video JOIN User)
2. **LEFT JOIN** — користувачі без відео (User LEFT JOIN Video)
3. **FULL OUTER JOIN** — усі користувачі та всі відео (User FULL OUTER JOIN Video)
4. **CROSS JOIN** — всі комбінації користувачів та відео (для potential audience)

### Багатотаблична агрегація

1. **JOIN + GROUP BY + ORDER BY** — топ авторів за сумарними переглядами
2. **JOIN + COUNT + GROUP BY** — відео з кількістю лайків та коментарів
3. **Підзапит** — автори, чий середній перегляд вищий за загальний середній
