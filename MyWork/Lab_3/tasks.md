# Lab 3 — OLTP: SELECT, INSERT, UPDATE, DELETE

## Завдання

Використовуючи БД VideoHub з Lab 2, виконати базові операції CRUD (Create, Read, Update, Delete).

### SELECT (Read)

1. Вибір усіх даних з таблиці User
2. Вибір конкретних колонок з WHERE — відео з переглядами > 10000
3. Вибір з сортуванням та LIKE — користувачі з username, що містить 'a', відсортовані за датою
4. Вибір з LIMIT — топ-3 відео за переглядами

### INSERT (Create)

1. Додати нового користувача та перевірити SELECT-ом
2. Додати нове відео та перевірити SELECT-ом
3. Додати новий коментар та перевірити SELECT-ом

### UPDATE

1. Збільшити лічильник переглядів відео на 1. До та після — SELECT
2. Змінити description користувача. До та після — SELECT

### DELETE

1. Видалити коментар (без FK-зв'язків на інші таблиці) — просте видалення
2. Видалити користувача, який має відео — перевірити CASCADE (видаляються відео, коментарі, лайки, підписки)
