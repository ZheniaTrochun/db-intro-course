# Лабораторна робота №2 — Інтернет-магазин електроніки

**Дисципліна:** Бази даних  
**Виконав:** Єремов Дмитро Миколайович, ІМ-51  
**Тема:** Перетворення ER-діаграми на схему PostgreSQL

Роботу виконано індивідуально на основі [моделі з лабораторної №1](https://github.com/ZheniaTrochun/db-intro-course/pull/324).

Основний документ — [звіт](REPORT.md). Скрипт `schema.sql` створює 9 таблиць, додає зразки даних і виводить кількість рядків у кожній таблиці. Файл [verification.txt](verification.txt) містить результат запуску вбудованого PostgreSQL-сумісного рушія PGlite (значення `server_version` — `19.0`).

## Порядок запуску

1. Відкрийте PostgreSQL через pgAdmin або інший клієнт.
2. Відкрийте `schema.sql` у Query Tool та виконайте скрипт повністю.
3. Перевірте виведену таблицю `table_name` / `row_count`; усі таблиці мають містити щонайменше 3 рядки.

Скрипт видаляє й створює лише схему `electronics_store`, щоб його можна було запускати повторно й не зачіпати інші схеми. У тестових записах `password_hash` — демонстраційні рядки, не справжні паролі чи придатні для входу хеші.

Для запитів до цих таблиць у наступних роботах використовуйте повне ім’я `electronics_store.table_name` або виконайте в новій сесії `SET search_path TO electronics_store, public;`.

## Файли

- `schema.sql` — DDL, обмеження, зразки даних і запит для перевірки кількості рядків.
- `REPORT.md` — опис таблиць, ключів, обмежень і припущень.
- `verification.txt` — фактичний результат запуску в PGlite; `schema.sql` також призначений для виконання в pgAdmin або іншому клієнті PostgreSQL.
- `CHECKLIST.md` — звірка результатів із вимогами лабораторної.
