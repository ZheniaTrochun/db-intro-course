# Лабораторна робота №3: SQL OLTP

**Виконав:** Єремов Дмитро Миколайович, ІМ-51  
**Формат виконання:** індивідуально  
**Предметна область:** інтернет-магазин електроніки

## Файли

- `oltp.sql` — послідовні приклади `SELECT`, `INSERT`, `UPDATE`, `DELETE` та перевірки результатів.
- `REPORT.md` — мета, опис запитів, очікувані й фактичні результати.
- `verification.txt` — результат виконання скрипту на зразковій схемі лабораторної №2.
- `CHECKLIST.md` — перелік вимог для перевірки перед здачею.

## Порядок запуску

1. У тій самій базі PostgreSQL виконайте `schema.sql` з лабораторної №2 (вона створює схему `electronics_store` і тестові дані).
2. Відкрийте `oltp.sql` у pgAdmin Query Tool і виконайте файл повністю.
3. Перегляньте результати `SELECT` у вкладці Data Output. Для перевірок після `INSERT` та `UPDATE` має відображатися тестовий товар; після `DELETE` запит має повернути 0 рядків.
4. Скрипт завершується `ROLLBACK`, тому тестові зміни не залишаються в базі.

У кожній із дев'яти таблиць початкової схеми є щонайменше 3 рядки; підтвердження кількості наведено в лабораторній №2 (`verification.txt`).
