# Checklist перед здачею

- [x] Є `SELECT` із `WHERE` та явним переліком полів.
- [x] Є `INSERT`, `UPDATE` з обмежувальним `WHERE` і `DELETE` з обмежувальним `WHERE`.
- [x] Після кожної зміни є перевірка через `SELECT` або `RETURNING`.
- [x] У звіті описані мета, очікувані та фактичні результати.
- [x] Зазначено послідовність запуску файлів і зв'язок зі схемою лабораторної №2.
- [x] Скрипт завершує демонстраційну транзакцію через `ROLLBACK`.
- [x] Перевірено назви таблиць і полів за `schema.sql` лабораторної №2.
