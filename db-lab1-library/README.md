# Лабораторна робота №1 - Бібліотека

**Дисципліна:** Бази даних  
**Тема:** Збір вимог та розробка схеми ER  
**Виконав:** Брюховецький Євген Вадимович, ІМ-51  

Основний документ - [звіт](REPORT.md). У ньому наведено вимоги, ER-діаграму, атрибути, пояснення зв'язків, обмеження та перевірочні сценарії.

- [ER-діаграма PNG](model/library-er.png) - зображення для перегляду та звіту.
- [ER-діаграма SVG](model/library-er.svg) - масштабоване зображення.
- [Вихідний опис DOT](model/library-er.dot) - редагований опис діаграми Graphviz.
- [Перевірка комплекту](CHECKLIST.md).

Роботу виконано індивідуально за погодженням із викладачем.

## Відтворення зображень

Потрібні Node.js та npm. У цій папці виконати:

```sh
npm install
npm run render
```

Скрипт читає `model/library-er.dot` і створює SVG та PNG. SQL-схема не входить до цієї роботи: її реалізацію передбачено в лабораторній №2.
